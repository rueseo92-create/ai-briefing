# 조용한 숲 (Quiet Forest)

무언가를 끊으려는 사람들이 각자 나무 한 그루씩 키우는 iOS 앱.
치료 앱이 아니라, 가볍게 계속 동기를 주는 앱이다.

## 원칙

- **사람끼리 오가는 건 응원(물 주기) 하나뿐.** 채팅, 댓글, 프로필, 팔로우, DM 없음.
- **이름은 자동.** `조용한 자작나무`처럼 숲이 붙여 주고, 바꿀 수 없다.
- **무엇을 끊는지는 기기 밖으로 나가지 않는다.** 숲에는 이름, 나무 모습, 지금 참는 중인지만 보인다. 정확한 일수, 돈, 이유도 공개하지 않는다.
- **실패해도 0이 되지 않는다.** 다시 하면 나무가 하루 시들고, "지금까지 참은 날"에서 하루만 빠진다.
- **끊는 것 전용.** 할 일, 집중 타이머, 출석 체크는 만들지 않는다. 나무는 날짜로만 자란다.

## 기능 (v0.2)

| 화면 | 내용 |
|---|---|
| 시작 | 끊을 것 고르기 → 마지막으로 한 때 → 목표 → 하루 비용·이유(선택) → 자동 이름 공개 |
| 내 나무 | 실시간 카운터, 목표 진행 바, 지금까지 참은 날, 버텨 낸 횟수, 아낀 돈, 오늘 받은 물, 위시리스트 진행 바 |
| 참기 | 10분 카운트다운, 끊는 이유 다시 보기. 그동안 숲에서 내 나무가 흔들리고, 누가 물을 주면 바로 알림 |
| 숲 | 다른 사람들의 나무. 참는 중인 나무가 앞에서 흔들림. 하루 3방울까지, 한 나무에 하루 한 방울 물 주기 (보낸 사람은 익명) |
| 알림 | 새 모습·배지·목표에 닿을 때, 참기 10분이 끝났을 때. 기기 안에서만 울리고 밤 9시~아침 9시에는 아침으로 미룸 |
| 설정 | 목표, 하루 비용, 이유, 위시리스트, 알림, 배지, 처음부터 다시 |

목표: 7일 · 30일 · 70일 · 100일 · 1년 · 평생 · 직접 입력(1일~10년). "지금까지 참은 날" 기준이라 한 번 다시 했다고 목표가 날아가지 않는다. 달성하면 축하 화면에서 다음 목표를 고른다. 평생은 끝이 없어서 다음 이정표까지 남은 날을 보여 준다.

v0.2에서 바뀐 것:

- **알림.** 처음 한 번 "나무가 자랄 때 알려 드릴까요?"를 묻고, 켜기를 누른 뒤에만 시스템 권한 창을 띄운다. 잠금 화면에 뜨는 문구에는 무엇을 끊는지, 돈, 이유가 나오지 않는다(`RemindersTests`가 확인). 다시 하면 알림 시각도 다시 계산한다.
- **참기 이어가기.** 참는 중에 앱이 꺼져도 15분 안에 다시 열면 참기 화면이 이어진다.
- **물 준 나무 기억.** 앱을 다시 열어도 오늘 물을 준 나무에는 또 줄 수 없다.
- **물방울 중복 방지.** 받는 쪽에서도 한 사람이 같은 날 준 물은 한 방울로 센다. 보낸 사람은 CloudKit이 붙이는 앱 전용 id로만 구분하고, 화면에 보이지 않으며 그날이 지나면 지운다.
- 예전(v0.1)에 저장한 기록은 그대로 읽힌다.

나무 단계: 씨앗(0일) → 새싹(1) → 묘목(3) → 어린 나무(7) → 나무(21) → 꽃 핀 나무(60) → 열매 맺은 나무(120) → 큰 나무(365)

## 실행하기 (Mac)

Xcode 16 이상이 필요하다. Xcode 프로젝트 파일은 저장소에 두지 않고 `project.yml`로 만든다.

```bash
brew install xcodegen
xcodegen generate
open QuietForest.xcodeproj
```

처음에는 **가짜 숲**(기기 안에서 만든 나무 36그루)으로 동작해서, 계정이나 서버 설정 없이 시뮬레이터에서 바로 돌려 볼 수 있다.

핵심 로직 테스트:

```bash
swift test --package-path Packages/ForestCore
```

## 진짜 숲 연결하기 (CloudKit)

서버를 따로 두지 않고 CloudKit 공개 데이터베이스를 쓴다. 유료 Apple Developer 계정이 필요하다.

1. `project.yml`의 `PRODUCT_BUNDLE_IDENTIFIER`를 내 것으로 바꾸고, Xcode에서 Team을 고른다.
2. Signing & Capabilities → **iCloud** 추가 → **CloudKit** 체크 → 컨테이너 생성 (예: `iCloud.com.내도메인.quietforest`).
3. `QuietForest/Forest/ForestService.swift`의 `AppConfig.cloudKitContainer`에 그 컨테이너 이름을 넣는다.
4. 앱을 한 번 실행해 레코드가 만들어지면, [CloudKit Console](https://icloud.developer.apple.com)에서 인덱스를 추가한다.
   - `Tree`: `updatedAt` (Queryable, Sortable), `startDay` (Queryable), `recordName` (Queryable)
   - `Cheer`: `target` (Queryable), `sentAt` (Queryable)
5. 출시 전에 스키마를 Production으로 배포한다.

## 운영 비용

| 항목 | 쓰는 것 | 비용 |
|---|---|---|
| 서버·데이터베이스 | CloudKit 공개 DB | 0원. 개발자 계정에 포함되고 사용자 수에 따라 무료 한도가 늘어난다. 한도를 넘으면 요금 대신 요청이 제한되는 방식이라 요금 폭주 걱정이 적다(출시 전에 Apple의 최신 정책을 다시 확인할 것) |
| 앱 빌드 | 맥에서 Xcode | 0원. EAS 같은 빌드 쿼터를 쓰지 않는다 |
| 자동 테스트 | GitHub Actions | 핵심 로직은 리눅스(싼 쪽), iOS 빌드는 PR·main·quiet-forest에서만. 맥 스튜디오를 자체 실행기로 등록하면 0원 |
| 스토어 | Apple Developer | 연 $99 (피할 수 없음) |

### 맥 스튜디오를 자체 실행기로 쓰기

1. 저장소 Settings → Actions → Runners → New self-hosted runner(macOS)의 안내대로 설치한다. 연구실 사람들과 섞이지 않게 **전용 일반 계정**에서 돌린다.
2. 저장소 Settings → Secrets and variables → Actions → Variables에 `IOS_RUNNER` = `self-hosted`를 추가한다.
3. 다른 사람이 무거운 작업을 돌리는 중이면 빌드가 느려질 수 있다. 빌드에 시간 제한(30분)을 걸어 두었다.

## 구조

```
Packages/ForestCore/     # UI 없는 핵심 로직 (성장, 이름, 물방울 한도, 공개 정보) + 테스트
QuietForest/
  App/                   # 앱 진입점, 탭
  Model/AppModel.swift   # 상태와 기기 저장
  Forest/                # 숲 연결: 가짜(Mock) / CloudKit
  Design/                # 색, 나무 그림
  Views/                 # 시작, 내 나무, 참기, 숲, 설정
```

숲에 나가는 데이터는 `PublicTree` 하나뿐이다. 여기에 필드를 추가하면 `PublicTreeTests`가 실패하도록 해 두었다.
